Format String Attack

printf(user_input) → de gebruiker bepaalt de format string → de stack lekt

STEP 0 / 0
Source Code (C)
int secret_value = 0x12345678;
 
void vulnerable_printf(char *user_input)
{
printf("User input: ");
printf(user_input); // ⚠ user = format
}
 
void safe_printf(char *user_input)
{
printf("%s", user_input); // 🛡 vast format
}
Kern: in de kwetsbare versie is user_input zélf de format string. Elke %x laat printf een woord van de stack lezen dat er helemaal niet als argument bij hoort. Met %s wordt zo'n woord als pointer gebruikt → geheugen wordt uitgelezen (leak) of crasht.
