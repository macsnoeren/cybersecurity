Timing Attack (Side-channel)

De responstijd verraadt hoeveel tekens al kloppen → geheim teken-voor-teken herstellen

Source Code (Python)
# VULNERABLE
def compare(guess, secret):
for i in range(len(secret)):
if guess[i] != secret[i]:
return False # stopt!
sleep(0.1ms) # per teken
return True
# SAFE
def compare(guess, secret):
result = 0
for i in range(len(secret)):
result |= guess[i] ^ secret[i]
# altijd hele lengte
return result == 0
Kern: de kwetsbare vergelijking returnt zodra één teken niet klopt. Hoe meer tekens vooraan kloppen, hoe langer de lus draait → hoe langer de responstijd. Die tijd is een side-channel: de aanvaller leest er het geheim uit zonder het ooit te zien. Constant-time vergelijkt altijd álle tekens, dus de tijd lekt niets.
